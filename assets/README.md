# Pocket Pal artwork

Original artwork created for Quadri’s assignment. You may copy, adapt and redistribute these assets as part of the assignment, the finished game and your portfolio.

- pocket-pal-icon.svg: editable 512×512 vector game icon.
- pocket-pal-icon.png: 512×512 raster icon, suitable for Flutter Image.asset.
- pal.svg: transparent vector mascot for the guide.
- pal-hello.gif: looping welcome illustration, 640×320.
- care-loop.gif: looping care concept, 640×320.

The GIFs are concept illustrations, not screen recordings of a finished Flutter game. Generate them again with npm run assets. No third-party character artwork is included.

To use the PNG in Flutter, copy it into app/assets/images/, declare that directory under flutter/assets in app/pubspec.yaml, and load it with Image.asset. For platform launcher icons, generate the platform-specific sizes separately.

## GitHub quest artwork

- quest-route.gif: 32-frame animated build route, 960×120.
